# Contributing to this guide

Corrections and additions are welcome.

## How to contribute

1. Open an issue first if you are unsure whether a change fits.
2. Keep each pull request to one section or one fix, so the history stays readable.
3. If a badge threshold or behaviour has changed, cite the source you checked.
4. Achievement behaviour changes over time; when in doubt, verify against a live profile before editing a claim.

## Style

Plain language, short sections, and no claim without a way to check it.
