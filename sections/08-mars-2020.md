# Mars 2020 Contributor (retired)

**Status:** retired. No new earners.

The Mars 2020 badge credited contributors to open source projects that flew on the Ingenuity helicopter, including the Linux and F Prime software stacks. When the mission contribution window closed, so did the badge.

Like the Arctic Code Vault badge, it remains visible on the profiles that earned it and cannot be obtained today by any amount of new activity.
