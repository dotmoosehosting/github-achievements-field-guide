# Documentation: the underrated contribution

Documentation pull requests merge at a higher rate than code for most contributors, because the review cost is low and the value is obvious to anyone who has answered the same question three times.

High value documentation work:

- The setup step that failed for you, fixed.
- The example that should exist for the feature everyone asks about.
- The error message, searched verbatim, that currently returns nothing.
- Translations and accessibility improvements to existing pages.

This guide is itself a documentation project, and every one of its sections reached the default branch through a reviewed style pull request flow: branch, commit, pull request, merge.
