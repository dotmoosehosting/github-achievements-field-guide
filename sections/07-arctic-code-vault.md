# Arctic Code Vault Contributor (retired)

**Status:** retired. No new earners.

In 2020 GitHub archived a snapshot of public repositories into the Arctic World Archive in Svalbard, as part of the GitHub Archive Program. Accounts whose code was included received the Arctic Code Vault Contributor badge.

Because the snapshot is a fixed historical event, this badge can never be earned now. Profiles that have it keep it permanently. It is listed in this guide because any honest catalogue of achievements has to separate the badges you can still chase from the ones that are simply history.
