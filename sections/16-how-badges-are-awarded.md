# How and when badges are awarded

Achievements are calculated automatically by GitHub from your account activity. Nobody applies for them and nobody can add them manually.

Timing facts worth knowing:

- There is a delay between qualifying activity and the badge appearing. Minutes is common; a day is not unusual; GitHub has publicly reported badge display incidents lasting longer.
- Activity on public repositories counts. Private repository activity counts only if you enable private contributions on your profile, and some badges are public-only regardless.
- When GitHub launches a new achievement, it has historically calculated it retroactively from your existing history.
- Badges, once earned, are not revoked for inactivity.

The practical consequence: do real qualifying work, then verify on your public achievements tab later, rather than refreshing the profile after every merge.
