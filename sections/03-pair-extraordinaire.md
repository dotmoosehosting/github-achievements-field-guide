# Pair Extraordinaire: co-authored commits in merged pull requests

**What it counts:** merged pull requests whose commits carry `Co-authored-by:` trailers crediting another GitHub user.

**Tiers:** Default 1, Bronze (x2) 10, Silver (x3) 24, Gold (x4) 48.

The trailer goes at the end of the commit message, separated from the subject by a blank line:

```text
Add guide section: co-author trailer format

Co-authored-by: Partner Name <12345678+partner@users.noreply.github.com>
```

Use your partner's GitHub noreply email so GitHub can attribute the co-authorship to their account. Every section of this guide was committed with a co-author trailer and merged through its own pull request, which is exactly the activity this badge measures: work that names the people (and bots) who built it with you.

Note: community trackers have reported periods where this badge stopped being awarded to new earners even though the qualifying activity is still recorded. Do the work anyway; GitHub has a history of calculating achievements retroactively when a badge returns.
