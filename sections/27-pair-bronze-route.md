# Pair Extraordinaire Bronze: 10 co-authored merged pull requests

Ten co-authored merges is where pairing stops being an accident and becomes a workflow. Ways teams get there naturally:

- Pair programming sessions where the driver commits with the navigator credited in the trailer.
- Bot assisted work: dependency updates and automation commits carrying the bot as co-author, merged through pull requests.
- Review driven fixes, where the reviewer's suggested change is committed with the reviewer credited.

The mechanic is always the same: a commit message ending in a properly formatted `Co-authored-by:` trailer, with the partner's GitHub noreply email, inside a pull request that merges.
