# Pull Shark Gold: 1024 merged pull requests

One thousand and twenty four merged pull requests is a career-scale number. The profiles that hold Gold Pull Shark usually got there through years of professional work landed in public, heavy open source maintenance, or both.

Perspective:

- At five merged pull requests a week, every week, Gold takes about four years.
- Maintainers of popular projects accumulate merges from their own repositories steadily, which is why so many Gold holders are maintainers rather than drive-by contributors.

Gold Pull Shark on a profile is best read as evidence of a long public track record. It is the hardest achievement tier to earn and the easiest to sanity check: the pull request history is right there.
