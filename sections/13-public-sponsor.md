# Highlight: Public Sponsor

**Type:** profile highlight, not an achievement badge.

**How it is earned:** sponsor an open source developer or project through GitHub Sponsors with a public sponsorship. Even a small one-time sponsorship counts; the highlight reflects that you fund open source, not how much you spend.

Sponsorships are real payments to real maintainers, so this is the one profile mark with a price tag attached. A one dollar sponsorship earns the same highlight as a large one.
