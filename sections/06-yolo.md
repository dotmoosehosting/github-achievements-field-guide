# YOLO: merge without a review

**What it counts:** merging your own pull request without a review. One time only, no tiers.

YOLO is the badge GitHub gives you for doing the thing every team policy tells you not to do. On a solo project with no branch protection, an ordinary merge of your own pull request earns it. On a repository with required reviews, it will not trigger until a pull request merges with no review recorded.

It carries no tiers and no ongoing value beyond completing the set, but it documents something real about solo development: a lot of useful software ships exactly this way.
