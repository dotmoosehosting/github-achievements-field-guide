# Sources and verification

Achievement thresholds are community verified: GitHub has never published a complete official specification. This guide's numbers were cross checked in November 2026 against the public profile achievements documentation in the community catalogues (the github-profile-achievements and github-achievements atlas projects) and against live profiles, including the profile this repository belongs to.

Verify anything in this guide the same way it was written:

- Open any GitHub profile's Achievements tab and compare.
- Read the community catalogues, which date their checks.
- Distrust any guide that promises a badge GitHub has retired or never released.
