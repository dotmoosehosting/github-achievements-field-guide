# Setting up Discussions with a Q&A category

Galaxy Brain requires Discussions, and specifically a Q&A category:

1. Repository Settings, Features, tick Discussions.
2. The default category set includes Q&A. Custom categories must use the question and answer format to be answerable; announcement and general formats have no accepted answer.
3. Only discussions in answerable categories can have an answer marked.

Repository owners can convert useful issues into discussions, and maintainers can mark answers in any thread. For your own questions, the asker accepts; for community questions, the asker or a maintainer accepts.
