# Quickdraw: close fast

**What it counts:** closing an issue or pull request within 5 minutes of opening it. One time only, no tiers.

Quickdraw rewards triage speed, in theory: the maintainer who opens a tracking issue, realises it duplicates another, and closes it immediately. In practice almost everyone earns it by accident at some point, usually by opening an issue in the wrong repository and closing it straight away.

It is the fastest badge to earn deliberately: open an issue in your own repository, close it within five minutes, done. There is no higher tier to chase.
