# Checklist: Bronze tier

Bronze (x2) thresholds:

- [ ] Pull Shark: 16 merged pull requests.
- [ ] Pair Extraordinaire: 10 co-authored merged pull requests.
- [ ] Galaxy Brain: 8 accepted answers.
- [ ] Starstruck: 128 stars on one repository.

Bronze is the tier of deliberate hobbyists: every number here is reachable in a season of consistent public work, except Starstruck, which depends on building something an audience wants.
