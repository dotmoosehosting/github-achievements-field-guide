# The FAQ lives in Discussions

This repository's Discussions tab holds its frequently asked questions as Q&A threads: one question per thread, with an accepted answer on each. That structure is deliberate. It is searchable, it is how GitHub intends project FAQs to work, and it demonstrates the Galaxy Brain mechanic with real achievement questions instead of filler.

If your question is not there, open a new Q&A discussion. Good questions get answered, and good answers get marked.
