# Heart On Your Sleeve (unreleased)

**Status:** unreleased experiment. GitHub briefly surfaced this badge in 2026 and then withdrew it, confirming it was never meant to launch yet. No public launch date exists.

**What it is expected to count:** reacting to things on GitHub with a heart reaction.

There is no way to force an unreleased badge to appear. The sensible play, and the one this guide follows, is to do the underlying activity genuinely: use heart reactions on issues, pull requests, and comments that deserve them. GitHub calculated Pull Shark and Starstruck retroactively from existing activity when those badges launched, so real history is the asset if this badge ever ships.
