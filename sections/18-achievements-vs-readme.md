# Achievements are not README badges

Two different things get called GitHub badges:

1. **Profile achievements**, the subject of this guide: awarded by GitHub, shown on the Achievements tab and profile sidebar, impossible to fake or embed manually.
2. **README badges**: images anyone can add to a README with markdown, usually from a badge service, showing build status, version, or anything else the author wants.

README badges are decoration and signalling. Achievements are a record. Confusing them leads people to paste achievement images into a README and believe they have earned something; GitHub's system does not work that way, and readers who know the difference can tell at a glance.
