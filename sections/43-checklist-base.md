# Checklist: every base achievement

The weekend checklist for the base tier of everything earnable:

- [ ] Pull Shark: 2 merged pull requests.
- [ ] Quickdraw: open an issue, close it within 5 minutes.
- [ ] YOLO: merge one of your pull requests with no review.
- [ ] Pair Extraordinaire: 1 merged pull request containing a co-authored commit.
- [ ] Galaxy Brain: 2 accepted answers in repository Discussions Q&A.
- [ ] Starstruck: 16 stars on one repository you created. (The only item on this list that needs other people.)

Highlights, in parallel:

- [ ] Developer Program Member: free registration.
- [ ] Public Sponsor: one public sponsorship, any size.
- [ ] Security Advisory Credit: be credited on a published advisory.
- [ ] Pro: hold a Pro plan.
