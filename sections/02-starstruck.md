# Starstruck: stars on a repository you created

**What it counts:** stars on a single repository you created. The count is per repository, not your account total.

**Tiers:** Default 16, Bronze (x2) 128, Silver (x3) 512, Gold (x4) 4096.

There is no shortcut here that stays inside GitHub's terms. Stars have to come from other people's accounts, so the only real strategy is the oldest one: build something people want, document it well, show it working, and put it where its audience already gathers.

What actually moves the number:

- A README that explains the problem and shows the result in the first screenful.
- A demo, screenshot, or recording near the top.
- Releases people can download instead of instructions they have to assemble.
- Sharing the project in the communities it was built for, once, with context.
