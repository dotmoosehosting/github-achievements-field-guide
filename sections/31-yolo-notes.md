# YOLO notes: branch protection changes everything

YOLO requires a pull request merged with no review. Two common reasons a merge does not award it:

- The repository requires approvals, and someone (even the author, where allowed) recorded one.
- The pull request was merged by a bot or automation that counts as a reviewer in the timeline.

On an unprotected personal repository, the plainest self merge earns it. Most long time GitHub users earned YOLO years before the badge existed and received it retroactively, which is why it shows up on so many senior profiles.
