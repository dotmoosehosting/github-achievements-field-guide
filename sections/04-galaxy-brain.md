# Galaxy Brain: accepted answers in Discussions

**What it counts:** replies you post in GitHub Discussions that get marked as the accepted answer.

**Tiers:** Default 2, Bronze (x2) 8, Silver (x3) 16, Gold (x4) 32.

Mechanics that matter:

- Only Q&A category discussions have accepted answers.
- The discussion author (or a maintainer) marks the answer.
- Since February 2024, accepted answers inside the github.com/orgs/community discussions no longer award this badge; repository discussions still do.
- Recent reports say upvotes and answer quality factor in more than they used to. A one-line answer marked accepted by a friend may not move the counter the way a genuinely useful answer does.

The Discussions tab of this repository holds a worked FAQ on achievements: real questions, each with an accepted answer, which is the shape of activity Galaxy Brain is meant to reward. The best long-term route is still the obvious one: answer real questions in projects you actually use, clearly enough that the asker marks yours.
