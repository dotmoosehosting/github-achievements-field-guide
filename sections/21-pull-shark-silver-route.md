# Pull Shark Silver: 128 merged pull requests

At 128 merged pull requests the badge stops being a side effect and starts describing a habit: sustained contribution over months or years.

What changes at this scale:

- Review speed matters more than finding work. Small, well described pull requests with tests merge; giant ones wait.
- Maintainers start recognising your name, which shortens every subsequent review.
- Your own projects become a meaningful share of the count if you consistently land work through pull requests.

There is no legitimate fast lane. Accounts that farm 128 junk pull requests in throwaway repositories hold a badge that convinces nobody who clicks through, and GitHub can and does treat coordinated spam as abuse.
