# Checklist: Silver tier

Silver (x3) thresholds:

- [ ] Pull Shark: 128 merged pull requests.
- [ ] Pair Extraordinaire: 24 co-authored merged pull requests.
- [ ] Galaxy Brain: 16 accepted answers.
- [ ] Starstruck: 512 stars on one repository.

Silver usually marks maintainers and long term contributors. The pull request and answer counts are habit scale; the star count is project scale.
