# How accepted answers work

Inside a Q&A discussion:

- Any participant can reply.
- The discussion author and repository maintainers see a Mark as answer control on each comment.
- Marking pins the comment as the accepted answer, with a visible marker, and it is that event that Galaxy Brain counts for the comment's author.
- An answer can be unmarked and a different one chosen; the system follows the current state.

Self answered questions (the maintainer asks and answers their own FAQ) are a normal, useful pattern for projects. Whether self accepted answers move the Galaxy Brain counter the same way third party acceptances do has been reported both ways since 2024; third party acceptances remain the reliable route, and they are also simply worth more as a signal.
