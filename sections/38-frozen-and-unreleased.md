# Frozen, retired, and unreleased badges: the honest list

Not every badge in the catalogue can be earned today. Sorting them honestly:

- **Retired forever:** Arctic Code Vault Contributor, Mars 2020 Contributor. Fixed historical events.
- **Unreleased:** Heart On Your Sleeve, Open Sourcerer. Surfaced accidentally in 2026, withdrawn, no launch date. Qualifying activity is still recorded and may count retroactively.
- **Reported frozen at times:** Pair Extraordinaire and Galaxy Brain have both had periods where qualifying activity stopped producing new awards, per community trackers, followed by periods where awards resumed. GitHub does not publish a live status page for individual badges.

The strategy this guide follows: perform the qualifying activity properly regardless, because records persist even when display pipelines wobble.
