# Pair Extraordinaire Silver and Gold: 24 and 48

Silver takes 24 co-authored merged pull requests; Gold takes 48. This guide repository itself is a demonstration: its sections landed as individual co-authored pull requests, so building the catalogue walked the counter to Gold in one project.

That is the honest shape of this badge at higher tiers. It accrues to people whose normal way of working names collaborators on every change: pair programmers, maintainers working with automation, and teams with a trailer habit. Forty eight is a lot of pull requests, but each one is small, and the repository that results is real: you are reading it.
