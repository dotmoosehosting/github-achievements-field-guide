# How tiers work: Default, Bronze, Silver, Gold

Most tiered achievements have four levels:

- **Default:** the base badge, shown without a multiplier.
- **Bronze:** labelled x2.
- **Silver:** labelled x3.
- **Gold:** labelled x4.

The x2/x3/x4 labels are tier names, not arithmetic: Gold Pull Shark is not four times the Default threshold, it is 1024 merged pull requests against Default's 2. Since September 2026, profiles display the highest tier you hold for each achievement rather than a stack of every tier.

Tier thresholds differ per badge because the underlying activities differ in effort. One co-authored merged pull request earns Pair Extraordinaire; one star earns nothing until fifteen more arrive.
